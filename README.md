# Kerby Family Amsterdam Guide

This folder is ready to publish with GitHub Pages.

## Files

- `index.html` — mobile landing page
- `cover.jpg` — cover image
- `amsterdam-guide.pdf` — complete five-page guide

## Publish

1. Create a new public repository on GitHub.
2. Upload all three files to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and the **/(root)** folder.
6. Save and wait a minute or two for the site address to appear.

Your URL will usually be:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
